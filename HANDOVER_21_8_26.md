## 6. Gotchas learned this session

- **`string_to_array(word, '')` does not split into characters** in Postgres — it returns the whole word as a single element, so a distinct-letter count built on it silently returns zero rows. Use `regexp_split_to_array(word, '')`.
- **`outer` is a reserved word** — it cannot be a column alias in `AS v(...)`. Use `outers` or similar.
- **`wordle_words` and `spelling_bee_puzzles` have UNIQUE `(play_date, language)`**; `word_of_the_day` the equivalent on `(date, level, language)`. A permutation `UPDATE` of dates collides mid-statement. Use two phases inside a transaction: shift the whole block a year forward into empty space, then assign the shuffled dates back.
- **`crossword_clue_bank.id` is `GENERATED BY DEFAULT AS IDENTITY`** — omit it from inserts. UNIQUE is `(word, language, level, clue_text)`, so `ON CONFLICT DO NOTHING` is safe.
- **Never propose ES Spelling Bee pangrams and then check them.** The dictionary holds singulars and infinitives only, accented. A hand-drafted list of 30 failed 21. Query `word_lists` for candidates instead — length 7–8, `~ '^[a-z]+$'`, exactly 7 distinct letters, not already used as a pangram.
- **`generate_batch.py` bumps `used_count` and `last_used_date` in the same transaction as the insert.** Deleting the puzzles afterwards does not roll the counters back.
- **RPE has no hint button.** `showHint` is declared (L222) with a render block (L1097) in `RandomPracticeExercise.jsx`, but `setShowHint(true)` appears nowhere — only three resets to `false`. Hints written for the question bank surface in **Topic Practice only**. Confirmed still true; ~5-line fix if ever wanted. (James clarified this session that TP was what he meant, so no change made.)

## 3. Gotchas learned this session

- **Rule-based British spelling over-generates, in both directions.** Blanket `-eled→-elled` produced `princelling`, `athelling` and `unparallelled` (British is *unparalleled*, single l) — 30 of 48 candidates were curated by hand instead. The `-our` rule tried `succory→succoury`; succory is chicory, unrelated. And *laborious, honorary, humorous, vigorous, vaporise* correctly keep `-or`/`-ise` in British English, so suffix allow-lists matter more than stem lists.
- **The repo's `import-word-lists.mjs` does not reflect what's in the DB.** It points at SOWPODS and this very Spanish package, but the live lists matched neither. Treat it as stale.
- **Help text should be English even on the Spanish side.** Those students are English speakers learning Spanish; rules in Spanish are one more thing to decode. The first Wordle help sheet had this backwards and was rewritten.
- **Large `INSERT..SELECT` needs chunking** through the MCP — 555k rows split by word length across five statements. A single nested-loop anti-join without an index hit the statement timeout.
- **Filesystem MCP still can't create files.** `HelpSheet.jsx` and both scripts were delivered as downloads for James to save. Worth remembering that the *first* run of a new script always fails with ENOENT until it's moved out of `~/Downloads`.
